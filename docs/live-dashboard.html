How to read the positions and prices

Each game has two economic outcomes: Team A wins or Team B wins. Every Kalshi outcome shows all four executable sides: Buy YES, Sell YES, Buy NO and Sell NO. Polymarket has one token per team. Its card uses a captured executable CLOB top quote when available; otherwise it explicitly says that only catalog metadata was captured. Buy is the best ask and Sell is the best bid. There is one market-level order-book control per game.
