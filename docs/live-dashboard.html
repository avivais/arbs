How to read the positions and prices

Each game has two economic outcomes: Team A wins or Team B wins. Kalshi lists a separate binary YES/NO contract for each team; Polymarket lists one outcome token per team. Buy is the lowest price currently offered to a buyer (ask). Sell is the highest current buyer (bid). “Indicative only” is discovery metadata, not an executable quote. “Not sampled” means the bounded depth collector did not select that outcome; it does not mean the book is empty.
